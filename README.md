# INSY7311 StudyFlow Prototypes

High-fidelity HTML prototypes for **StudyFlow** - a mobile application designed to help tertiary students manage their academic workload effectively.

## 📱 About StudyFlow

StudyFlow addresses time management challenges faced by tertiary students through:
- **Intelligent Assignment Tracking** - Visual status indicators and automatic deadline management
- **Smart Study Planning** - Personalized study session recommendations
- **Progress Visualization** - Weekly dashboards and achievement celebrations
- **Stress-Reducing Design** - Calming interface with realistic goal-setting

## 🎨 Design Principles Demonstrated

These prototypes showcase five fundamental design principles:

1. **Balance** - Symmetrical layouts and even whitespace distribution
2. **Contrast** - Color-coded urgency (red/amber/green) and typographic hierarchy
3. **Proximity** - Gestalt grouping through spatial relationships
4. **Simplicity** - Minimal color palette and generous whitespace
5. **Visual Hierarchy** - Clear information prioritization
